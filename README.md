# Jean Reno R — Personal Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — portfolio content and structure
- `style.css` — responsive layout, colors, typography, and project illustrations
- `script.js` — mobile menu, active navigation, current year, and copy-email interaction

## Run locally

1. Download and extract the project ZIP.
2. Open the extracted folder.
3. Double-click `index.html` to preview it in a browser.

The Google Fonts import requires an internet connection; the site otherwise uses regular browser HTML/CSS/JavaScript.

## Publish using GitHub Pages

1. Sign in to https://github.com/ or create an account.
2. Click **New repository**.
3. Name the repository `jean-reno-portfolio` (or another name you prefer).
4. Set it to **Public**, then create the repository.
5. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. Do not upload only the ZIP file.
6. Open the repository's **Settings** tab.
7. Select **Pages** from the sidebar.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose branch **main** and folder **/(root)**, then click **Save**.
10. Wait a few minutes. GitHub Pages will show your published website URL in the Pages section. It will usually look like:
    `https://YOUR-GITHUB-USERNAME.github.io/jean-reno-portfolio/`
11. Open the URL on your phone and check that all sections and links work.
12. Copy the real published URL and submit it to the Google Drive folder or form specified by your internship coordinator.
